## Why

仓库 README 未完整覆盖定位、边界、安装、验证、安全、故障和发布证据，读者无法从入口文档建立可执行的正确心智模型。

## What Changes

- 按 `full-stack-doc` 的 插件 README 模板补充证据化入口文档。
- 从 manifest、技能目录、锁文件、测试和工作流读取事实，并保留原有说明。
- 增加定位、架构、边界、验证、安全、故障与发布生命周期内容。

## Capabilities

### New Capabilities

None. This is a documentation-only change and `skip_specs: true` is set.

### Modified Capabilities

None.

## Impact

Only repository README files and this OpenSpec documentation change are affected. Runtime behavior, manifests, APIs, locks, and published tags do not change.
